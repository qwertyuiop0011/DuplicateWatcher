DupWatch.ps1 - change guide: "content comparison" option (내용 비교)
=======================================================================

WHAT THIS ADDS
  A new on/off setting, "내용 비교" (content comparison), that controls the
  file-hash check:

    on  (default)  Same name but different contents  -> the new file is RETAINED
                   (left where it is, untouched). Only files whose contents are
                   identical get moved/deleted.
    off            Same name is enough -> the new file is moved/deleted
                   WHATEVER its contents. In delete mode it is deleted for good.

  Controls:
    Command line:  .\DupWatch.ps1 check on
                   .\DupWatch.ps1 check off
    Menu (TUI):    new item 4 "내용 비교 끄기 / 켜기". The items after it move down
                   by one, and "종료" (quit) is now item 0.

  Behavior change vs. the previous version:
    Before, a same-name file with DIFFERENT contents was always moved to the
    duplicate folder (even in delete mode). With content comparison ON it now
    stays in place instead. With it OFF, it is moved (move mode) or deleted
    (delete mode).

HOW TO USE THIS GUIDE
  Apply the 19 steps below to your current DupWatch.ps1, top to bottom.
  For each step:
    1. Search for the text between "----- FIND -----" and "----- REPLACE WITH -----".
       Copy it exactly, including the spaces at the start of each line.
    2. Replace it with the text between "----- REPLACE WITH -----" and "----- END -----".
  Every FIND text appears exactly once in the file.
  The marker lines themselves ("----- FIND -----" etc.) are NOT part of the code.

  IMPORTANT: save the file as "UTF-8 with BOM" when you're done (VS Code: bottom
  right "UTF-8" -> "Save with Encoding" -> "UTF-8 with BOM"). Otherwise Windows
  PowerShell 5.1 shows the Korean text as garbage.

  Or simply use the attached new DupWatch.ps1, which already has every change.

# 성공하면 $true.
function Remove-DuplicateFile([System.IO.FileInfo]$Target, [System.IO.FileInfo]$Kept, $Cfg) {
    if ($Cfg.Mode -eq 'Delete') {
        if (Test-SameContent $Target $Kept) {
            try {
                [System.IO.File]::Delete($Target.FullName)
                Write-DupLog "중복 파일 삭제: $($Target.Name)"
                return $true
            } catch {
                Write-DupLog "삭제 실패 $($Target.Name): $($_.Exception.Message)"
                return $false
            }
        }
        # 이름만 같고 내용이 다르면 절대 지우지 않고 이동시킴
        Write-DupLog "내용이 $($Kept.Name) 와(과) 달라 삭제 대신 이동: $($Target.Name)"
    }
----- REPLACE WITH -----

=======================================================================
  .\DupWatch.ps1 check off      -> 내용 비교를 설정했습니다: 꺼짐
  .\DupWatch.ps1 status         -> a "내용 비교:" line is shown
  .\DupWatch.ps1                -> the menu shows a "내용 비교" row and item "4 내용 비교 켜기"

  If DupWatch was already running, it picks up the new setting automatically
  within about 2 seconds. To load the new CODE, though, restart it once:
    .\DupWatch.ps1 stop
    .\DupWatch.ps1 start
